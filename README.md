# Maria Anayat — Speech & Language Therapist

Portfolio site for Maria Anayat, speech and language therapist and special education teacher (hearing impairment), founder of [VoiceForUnheard](https://voiceforunheard.vercel.app/).

Built with React + Vite. Colours and fonts (Fraunces, DM Sans) match VoiceForUnheard.

```bash
npm install
npm run dev     # local preview
npm run build   # production build in dist/
```

All text lives in `src/data/portfolio.js`.
